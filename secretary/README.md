# 비서(Bees) 워크플로우

김예희(코칭하는 회계사)의 개인 비서 워크플로우입니다. `/비서`를 부르면 일일 브리핑을 시작합니다.

## 사용법
- **`/비서`** — 일일 브리핑 시작. 오늘 첫 호출이면 먼저 전날 완료 여부를 체크리스트로 묻고, 답변을 반영한 뒤 인쇄용 브리핑을 만듭니다.
- 일요일에는 밀린 일(2026-08-30 이후) 검토가 함께 진행됩니다.

## 구성
```
.claude/
  commands/비서.md          # /비서 진입점 (슬래시 커맨드)
  skills/secretary/SKILL.md  # 워크플로우 본체(규칙·실행 순서)
secretary/
  ledger/settings.md         # 집 주소·업무 습관·검토 일정·규칙(고정)
  ledger/tasks.md            # 모든 업무(활성/막힘/완료/취소), ID(T###)로 관리
  ledger/blog.md             # 블로그 발행 현황
  ledger/newsletter.md       # LinkedIn 뉴스레터 현황
  templates/briefing-template.html  # 인쇄용 브리핑 템플릿(흑백)
  briefings/                 # 생성된 브리핑(YYYY-MM-DD.html)
  manuscripts/               # 확정 블로그 원고(YYYY-MM-DD-제목.md)
```

## 핵심 원칙
- 완료는 **사용자가 명시한 것만** 반영(시간 경과·체크박스로 추측하지 않음).
- 완료·취소도 **삭제하지 않고 이력 보존**.
- **실제 마감일은 임의 변경 금지**(계획일만 이동 가능).
- 발행일·URL·사례·수치를 **지어내지 않음**(모르면 "미기록").
- Google Calendar는 **읽기 전용**. (현재 OAuth 만료 상태 — 재인증 필요)
- 브리핑은 흰 바탕·검정 글자만, 상단 인쇄 버튼, 4개 섹션 고정: 오늘 할 일 / 오늘 일정 / 내일 일정 / 블로그 현황.

## 원장 갱신
원장(`secretary/ledger/*.md`)은 상태가 바뀔 때 갱신하며, 세션 간 보존을 위해 커밋해 두는 것을 권장합니다. 커밋은 사용자가 요청할 때만 수행합니다.
